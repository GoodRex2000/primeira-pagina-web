# Do zero ao primeiro site

Uma página em português para quem está começando a criar sites. Ela apresenta HTML, CSS, Git e GitHub Pages em uma sequência simples, com um exemplo de organização de arquivos.

Projeto individual da disciplina Desenvolvimento Web I, criado por Lázaro Fornari. O tema é independente do Projeto Integrador.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: aparência e adaptação para telas menores.
- `RELATORIO.md`: processo de construção e conceitos estudados.

O site usa somente HTML e CSS, sem JavaScript, framework, tema pronto ou arquivos externos. Para testar localmente, abra `index.html` no navegador. O relatório também contém o passo a passo da publicação.
