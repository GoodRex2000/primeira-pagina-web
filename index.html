NA PRÁTICA

Comece pequeno.
Publique de verdade.

Uma única página já é um projeto completo para aprender. Este site, por exemplo, usa somente dois arquivos para a interface: HTML para o conteúdo e CSS para o visual.

  • Escreva um assunto que você conhece.
  • Separe o conteúdo em seções claras.
  • Teste no computador e no celular.
  • Publique e abra o link em outra aba.

SEM COMPLICAÇÃO

Três palavras para guardar

Elas aparecem o tempo todo quando você começa a criar para a web.

01 /

Repositório

É a pasta do projeto no GitHub, com os arquivos e o histórico das alterações.

02 /

Commit

É um registro de uma mudança. Uma mensagem clara ajuda a entender o que foi feito.

03 /

Hospedagem

É o serviço que deixa os arquivos disponíveis para as pessoas acessarem pelo navegador.
